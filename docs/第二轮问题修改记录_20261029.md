# 第二轮问题修改记录（2026-10-29）

对应 `main@270fc02` 的第二轮审查。V10 迁移和业务代码共同修复隐私、并发、会话与内容一致性问题。

## 主要修改

| 问题 | 修改 |
|---|---|
| 游客可看学院、专业、年级和逐笔流水 | 公开成员页只返回昵称、总分、来源汇总和能力图；逐笔明细仅本人、队长、积分管理员、教师可见 |
| 战队成员唯一键包含 `team_id`，同一用户可同时加入多队 | V10 先软退队清理历史重复，再用只按 `user_id` 生成的 `active_user_id` 建唯一约束 |
| 本人改密只销毁当前会话 | 改密后撤销该用户全部 SessionRegistry 会话；并发会话过期改为跳转 `/login?expired` |
| 最后一个启用的超管可以自降权或被禁用 | 锁住 SUPER_ADMIN 角色行，并保证至少保留一个启用超管 |
| 旧版本升级后旧账号不强制改密 | V10 将迁移时已有账号全部标记为下次登录必须改密 |
| 同一漏洞编号可用不同等级重复提交 | 已有漏洞再次提交时，等级不一致直接拒绝 |
| 文章/公告保存与媒体绑定不在同一事务 | 文章、封面和公告附件改为同一服务事务内保存；失败整单回滚 |
| 已通过评论无法下架 | 评论状态增加 `REVOKED`，后台增加已通过评论列表与下架操作 |
| 词库更新后提交/发布不复查 | 文章提交、文章发布、评论审核通过时重新检查当前敏感词 |
| 积分和兑换允许自审 | 禁止审核自己的积分申请、申诉和兑换申请；禁止直接为自己的成绩入账 |
| 待处理申诉/兑换存在并发重复窗口 | V10 增加 OPEN 申诉与 PENDING 兑换的生成列唯一约束，并清理历史重复 |
| 登录没有失败限流 | 同一 IP + 登录名 15 分钟内失败 5 次后阻止后续密码校验 |
| 比赛档案增删改不写审计 | 比赛新增、编辑、删除和 CSV 导入补 `audit_log` |
| 成员页面部分 Controller 暴露原始异常 | 成员侧内容、资料、战队和兑换只捕获 `BizException`，其他异常交给全局处理器 |
| 已发布文章错误显示编辑入口 | 只有 DRAFT / REJECTED 文章对作者显示并可进入编辑页 |
| Markdown 允许外链图片但 CSP 阻止 | 外链图片统一只允许 HTTPS，CSP `img-src` 同步放行 HTTPS |
| 备份失败会遗留明文 dump | 备份使用 `umask 077`、唯一临时目录和 `EXIT` 清理 trap |
| 发布目录一直累积 | 发布成功后仅保留最近 5 个 release |
| README 技术版本错误 | 更新为 Spring Boot 4.1.2 / Spring Security 7.1.2 |
