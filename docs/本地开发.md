## 数据库

```sql
CREATE DATABASE IF NOT EXISTS assoc_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER IF NOT EXISTS 'assoc_app'@'127.0.0.1' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON assoc_dev.* TO 'assoc_app'@'127.0.0.1';
FLUSH PRIVILEGES;
```

不要手工建业务表。`spring.jpa.hibernate.ddl-auto=validate`，结构只由 Flyway 管。

## 环境变量

`DB_URL` / `DB_USER` / `DB_PASSWORD` / `ADMIN_USERNAME` / `ADMIN_PASSWORD` / `POINTS_BACKFILL_START` / `DEMO_DATA_ENABLED`，见 README 的表。
`ADMIN_PASSWORD` 至少 12 位、含大小写/数字/符号三类；缺失或太弱应用会拒绝启动。
演示数据默认关闭，开发时可以 `DEMO_DATA_ENABLED=true` 加载示例荣誉。

只对当前 PowerShell 窗口生效，换窗口要重设。

## 排错

**8080 被占**
```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen | Select-Object OwningProcess
```
确认是旧 Java 进程再停。临时换个端口：`$env:SERVER_PORT = '8081'`。

**连不上库**：先 `Test-NetConnection 127.0.0.1 -Port 3307`；再用应用账号直连一次；检查 `SHOW GRANTS FOR 'assoc_app'@'127.0.0.1'`。

**Flyway 校验失败**：查 `flyway_schema_history`。已执行过的脚本不要改，改了就新建 V9、V10。开发库可以整个重建：
```sql
DROP DATABASE IF EXISTS assoc_dev;
CREATE DATABASE assoc_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```
只对确认可丢的本地库这么做。

**首次登录被强制改密**：这是设计行为；改完密码会用新账号重新登录。如果你本地测试不想被拦，用 `DEMO_DATA_ENABLED` 不影响的已有账号登录即可，改一次密码就行。

**搜索结果为空 / 中文乱码**：确认数据库是 `utf8mb4`，CSV 导入文件是 UTF-8。
