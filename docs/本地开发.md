## 数据库

```sql
CREATE DATABASE IF NOT EXISTS assoc_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER IF NOT EXISTS 'assoc_app'@'127.0.0.1' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON assoc_dev.* TO 'assoc_app'@'127.0.0.1';
FLUSH PRIVILEGES;
```

不要手工建业务表。`spring.jpa.hibernate.ddl-auto=validate`，结构只由 Flyway 管。

## 环境变量

`DB_URL` / `DB_USER` / `DB_PASSWORD` / `ADMIN_USERNAME` / `ADMIN_PASSWORD` / `POINTS_BACKFILL_START` / `DEMO_DATA_ENABLED`，见 README 的表。
`ADMIN_PASSWORD` 至少 12 位、含大小写/数字/符号三类；缺失或太弱应用会拒绝启动。
演示数据默认关闭，开发时可以 `DEMO_DATA_ENABLED=true` 加载示例荣誉。

只对当前 PowerShell 窗口生效，换窗口要重设。

## 集成测试（*IT）与 E2E

`mvn verify` 会用 Testcontainers 起一个 `mysql:8.0.43`，跑完自动销毁；CI 的 `integration-tests` 任务也是这条命令（加 `-DskipUnitTests=true`）。

**本机没有 Docker**：指向一个专供测试的 MySQL 空库（名字建议 `assoc_it`，用例会建表写数据）：

```powershell
& $mvn verify -DskipUnitTests=true `
  "-Dit.datasource.url=jdbc:mysql://127.0.0.1:3309/assoc_it?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false" `
  -Dit.datasource.username=assoc_it -Dit.datasource.password=assoc_it_pw
```

既没有 Docker 也没配外部库时，`*IT` 整类跳过，`mvn test` 仍然只跑单元测试。外部账号需要对测试库有建表权限；`FlywayMigrationIT` 还会临时创建并删除一个 probe 库，需要 `CREATE/DROP DATABASE` 权限。

**浏览器 E2E**（Playwright，首次需要下载 Chromium；本机可设 `E2E_CHANNEL=msedge` 直接用 Edge）：

```powershell
& $mvn -Dmaven.test.skip=true package
cd e2e
npm ci
npx playwright test
```

E2E 需要 `DB_URL / DB_USER / DB_PASSWORD / ADMIN_PASSWORD` 指向一个可迁移的 MySQL 库；Playwright 会自己用 jar 起应用（已有服务时设 `E2E_NO_WEBSERVER=1`，或让它复用 8080）。

离线构建（依赖已缓存在学习工作区的 m2repo 时）：

```powershell
& $mvn -o -B -ntp `
  "-Dmaven.repo.local=C:/Users/16254/Documents/deepseek-harness/default-workspace/learning-workspace/tools/m2repo" `
  "-Daether.enhancedLocalRepository.trackingFilename=_disabled.tracking" test
```

## 排错

**8080 被占**
```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen | Select-Object OwningProcess
```
确认是旧 Java 进程再停。临时换个端口：`$env:SERVER_PORT = '8081'`。

**连不上库**：先 `Test-NetConnection 127.0.0.1 -Port 3307`；再用应用账号直连一次；检查 `SHOW GRANTS FOR 'assoc_app'@'127.0.0.1'`。

**Flyway 校验失败**：查 `flyway_schema_history`。已执行过的脚本不要改，改了就新建 V9、V10。开发库可以整个重建：
```sql
DROP DATABASE IF EXISTS assoc_dev;
CREATE DATABASE assoc_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```
只对确认可丢的本地库这么做。

**首次登录被强制改密**：这是设计行为；改完密码会用新账号重新登录。如果你本地测试不想被拦，用 `DEMO_DATA_ENABLED` 不影响的已有账号登录即可，改一次密码就行。

**搜索结果为空 / 中文乱码**：确认数据库是 `utf8mb4`，CSV 导入文件是 UTF-8。
